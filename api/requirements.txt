# Dependencies of the API image. PINNED with == on purpose.
#
# Why exact pins and not floors like the root requirements.txt: this file builds a container, and
# a build that resolves "whatever is latest on PyPI" means the same commit produces a different
# image every time — which is how a rollback stops meaning anything. The pipeline's own
# requirements.txt keeps floors because it runs on your machine, not in an image.
# Versions = what the suite was run against (14-sep-2026). To upgrade: raise a pin on purpose,
# run the suite, deploy.
fastapi==0.120.4
uvicorn==0.38.0
neo4j==6.2.0
# Embeddings for the semantic half of the search (services/vector.py) and the LLM router of
# POST /query (services/analyzer.py).
google-genai==2.4.0
python-dotenv==1.2.2
# The API imports pipeline/parseo.py (the retrieval filters by the content types it declares),
# and that module reads PDFs with PyMuPDF.
pymupdf==1.27.2.3
slowapi==0.1.10
# The official MCP SDK: the remote server in api/routers/mcp_remote.py (Streamable HTTP, contract
# mcp/v1). PINNED TO THE SAME VERSION the other Nomos instances run, on purpose: they all implement
# the same contract and the `inputSchema`/`outputSchema` a client receives are GENERATED by this SDK
# from the signatures and the Pydantic models, so a different SDK is a different published surface.
# Also: mcp 2.0.0 moved/removed `mcp.server.fastmcp` — going to 2.x means migrating the router, not
# bumping a number.
mcp==1.27.1
# The admin/v1 descriptor is built from the active domain profile (profiles/*.yaml via

pyyaml==6.0.3
